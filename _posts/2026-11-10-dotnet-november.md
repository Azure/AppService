The November 2026 .NET release is scheduled to go live on November 10, 2026. This is a security release, so teams running supported .NET versions should be prepared to evaluate and deploy the updates promptly.

This release also marks an important milestone for the .NET ecosystem: .NET 11 reaches General Availability (GA).

## November 2026 releases

The following .NET runtime versions will be available:

- .NET 11.0.0 GA
- .NET 10.0.15
- .NET 9.0.23
- .NET 8.0.34

## Prepare for the release

Because this release includes security updates, we recommend that service and application owners review their .NET dependencies and prepare their validation and deployment processes ahead of the November 10 release.

Teams planning to adopt .NET 11 can also begin preparing for the GA release.

As always, timely adoption of security updates is an important part of keeping applications and services protected and maintaining a strong security posture.
